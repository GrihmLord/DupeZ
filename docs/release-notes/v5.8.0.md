# DupeZ v5.8.0

DupeZ v5.8.0 promotes the repaired bounded-resilience architecture from
v5.7.9 and tightens performance, AI overload handling, dependency scope, and
release repeatability.

## Highlights

- Standard effects are owned by the pinned Kalirenegade Clumsy process.
- Native WinDivert hosts only namespaced DupeZ extensions, including the
  bounded Connection Resilience and experimental Pulse Resilience labs.
- One process-wide owner prevents competing packet engines and preserves the
  lease whenever shutdown cannot be confirmed.
- Periodic traffic snapshots are coalesced away from the packet capture
  thread, keeping capture responsive during analysis windows.
- Smart Ops accepts at most two simultaneous provider calls and uses the
  validated offline advisor during overload or provider failure.
- Unused pandas and its release weight are removed; XLSX import/export still
  uses openpyxl and the optional audio/model paths retain NumPy.
- The disposable packaging environment is `.release-venv`, avoiding the
  reproducible IDE formatter lock seen with `.build-venv`.
- Release preflight now rejects version drift in the active PowerShell/CMD
  drivers and GitHub release workflows.
- The logged UAC finalizer preserves native stderr diagnostics and decides
  success from the protected child exit code, so PyInstaller warnings cannot
  terminate an otherwise successful release build.
- Split-helper authentication resolves the token sentinel from Windows' real
  Local AppData profile on both sides of UAC, including isolated frozen tests.
- Nested release-phase failures now propagate to the launcher and remain
  failed instead of being recorded as complete.
- Frozen dashboard automation now uses Windows' complete native `INPUT` union,
  and cleanup tolerates the intentionally elevated helper without hiding the
  original lifecycle result. The validator rebinds Qt's current dashboard
  handle before each shortcut when a runtime transition recreates the window,
  and activates it through the documented Windows input-queue boundary.

## Safety boundary

DupeZ is for private servers, devices and networks you own, or environments
where you have explicit authorization. Bounded extensions release
automatically below 30 seconds, fail open on deadline/overflow, and do not
promise immunity from a game or server timeout.

## Release validation

The public artifacts are ready only after all of the following pass against
the exact v5.8.0 commit and bytes:

1. Full automated tests and source release preflight.
2. Hermetic GPU and Compat builds from hash-pinned locks.
3. Frozen import-boundary verification for both executables.
4. Non-admin GPU and admin Compat runtime validation.
5. Opt-in authorized hardware smoke and the manual validation record.
6. Defender scan, SHA-256 list, SBOM/VEX, provenance, and updater sidecars.
7. Draft-release download and hash verification before publication.

Existing v5.7.9 installations may upgrade through the signed updater path
when v5.8.0 is published with valid updater sidecars. If the public build is
explicitly unsigned, Windows publisher warnings remain expected and the
release page must disclose that fact.
