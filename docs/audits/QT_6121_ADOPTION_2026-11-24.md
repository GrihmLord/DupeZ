## Source and security findings

The new QtBase binary metadata, including Core, and SVG metadata declare the
same revisions as their respective source exports. This resolves the previous
QtBase/Core revision discrepancy for this candidate. ImageFormats and
Translations metadata omit revision values; Translations also omits a source
SPDX file. Missing export Git metadata and the exported `.tag` difference remain
explicit in the [source correspondence record](../../packaging/license-evidence/qt-6121-source-correspondence-2026-11-24.json).
No native library compilation is inferred from metadata or checksum matches.

The pinned QtBase source contains all three production bounds checks in the
two vendor CVE-2026-116337 patches. Unique exact postimages and reverse patch
checks support that finding. The insertion-only second patch can also pass a
forward check because its trailing context repeats, so forward failure is not
the basis of the conclusion. Vendor test functions are present but were not
executed. See the [source fix review](../../packaging/license-evidence/qt-6121-network-source-fix-2026-11-24.json).
Qt Network remains excluded from the new frozen artifacts; canonical Qt 6.11.2
is unchanged and remains affected.

All 2,745 retained IUP 3.30 source files were compared with official historical
SVN revision 5892: 2,040 match exactly and 705 differ only in CRLF/LF line
endings. No file is missing or otherwise different. All 542 `src` and 35
`include` files match exactly. The new bounded verifier rejects malformed,
substituted and unsafe inputs; independent agent review found and corrected a UTF-16
XML declaration-filter bypass. See the [complete archive review](../../packaging/license-evidence/iup-source-archive-review-2026-11-24.json).
This does not identify the original DLL's exact compiler inputs or reproduce it.

The versioned translation recipe rebuilds all 314 Qt catalogs byte for byte,
including all 33 retained QtBase catalogs. All 324 Linguist source files match
the source SPDX checksums as raw bytes or declared line-ending equivalents;
the official lrelease binary declares the same revision as the source export.
Seven private tool/runtime files pass pinned signature and byte checks. This
is translation reconstruction with the official tool, not recompilation of
lrelease or Qt. See the [translation evidence](../../packaging/license-evidence/qt-6121-translations-2026-11-24.json).

The [separate image probe](../../packaging/license-evidence/qt-6121-image-probe-2026-11-24.json)
confirms the historical 38-byte WebP still fails to decode. PNG and patterned
WebP controls match all 256 pixels; empty/truncated controls are rejected.
Twenty-six relevant loaded native files match their expected origins. This
limited functional check does not establish decoder-wide security coverage.

The Qt source-correspondence and translation verifiers hold Windows sharing-read locks over
pinned archive reads; translation execution also locks its executable and DLLs
through signature inspection and use. Mutation and positive-control tests cover
these boundaries. Earlier unlocked observations are retained as diagnostics.

## Recipient route and remaining work

3.13.17 interpreter. Acquire and verify the private Microsoft package stage
using the [private-stage recipe](MSVC_PRIVATE_STAGE_2026-11-24.md), then prepare
this candidate and an isolated profile:

```powershell
python -I scripts/prepare_qt_candidate.py --profile frozen-raster-no-qtnetwork --cache <verified-input-cache> --output build/qt6121-candidate
```
